## 프로젝트 개요
프로젝트마다 사용되는 관리자 페이지 템플릿의 공통 레이아웃, 컴포넌트 및 유틸리티를 **TypeScript**로 마이그레이션하여 **코드 품질과 유지보수성을 향상**시킨 프로젝트입니다. MDI(Multiple Document Interface) 환경에서의 **렌더링 최적화와 성능 개선**에 중점을 두었으며, **타입 안정성 확보**를 통해 개발자 경험을 크게 개선했습니다.

## 주요 성과

### 개발 경험 개선

- **TypeScript** 도입으로 컴파일 타임에 오류 감지 및 예방
- 자동 완성 및 타입 추론 기능으로 **개발 생산성 향상**
- 명시적인 인터페이스 정의로 코드 **가독성 및 유지보수성 증대**
- 동료 개발자들로부터 개발 경험 향상에 대한 **긍정적 피드백 확보**

### 렌더링 성능 최적화

- MDI 환경에서 발생하던 **불필요한 렌더링 문제 해결**
    - **React.memo**를 활용하여 Recoil 상태 변경 시 비활성 탭의 리렌더링 방지 로직 구현
- **React.lazy**와 코드 스플리팅을 통한 초기 로딩 시간 단축
- 주요 성능 개선 지표:
    - **First Contentful Paint**: 79% 감소 (1.0초)
    - **Largest Contentful Paint**: 60% 감소 (4.2초)
    - **Total Blocking Time**: 31% 감소 (150밀리초)
    - **Speed Index**: 67% 감소 (1.9초)
